# MarcioHLE

**MarcioHLE** is an independent emulator project focused on preserving and exploring old mobile applications and games.

## Main Features

### Independent Code
MarcioHLE is developed independently, with its own codebase and without copying source code from other projects.

### Individual Development
The project is created and maintained by a single developer:

- **Márcio Games (Marcio Oliveira)**

All development, testing, research, and improvements are done by the creator of the project.

### Independent Project
MarcioHLE is not supported, endorsed, or maintained by any other emulation project. It follows its own development path and goals.

## Project Goal

The goal of MarcioHLE is to study, preserve, and improve compatibility with older software, helping keep the history of mobile games and applications alive.

## Respect for Other Projects

MarcioHLE recognizes the work of all developers who contributed to emulation and digital preservation.

Existing projects serve as inspiration and technical references, but MarcioHLE follows its own implementation.

## Transparency

The project aims to maintain a development environment based on:

- Clean code.
- Respect for software licenses.
- Transparency in development.
- Respect for original creators.

## Credits and Thanks

Special thanks to all developers, researchers, and communities that helped document old systems, file formats, and technologies throughout the history of mobile computing.

Thanks to open-source projects and libraries that support the software development community.
